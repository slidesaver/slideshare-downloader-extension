# SlideShare Downloader – PDF, PPT & Scribd (Browser Extension)

Free browser extension for **[SlideShare Downloader](https://slidesharedownloadr.com/)**. Download public SlideShare presentations as **PDF, PPT or images**, and public Scribd documents with the [Scribd Downloader](https://slidesharedownloadr.com/scribd-downloader/). No login, no data collected.

## Features
- One-click toolbar popup: detects the SlideShare or Scribd page you are on.
- Right-click menu: "Download with SlideShare Downloader" on any SlideShare/Scribd link.
- Works in Chrome, Edge, Opera, Brave and other Chromium browsers.
- Firefox version: [Firefox Add-ons](https://addons.mozilla.org/) (search "SlideSaver").

## Install (Chrome / Edge / Opera / Brave)
1. Download `slideshare-downloader-extension.zip` from the [Releases](../../releases) page and unzip it.
2. Open `chrome://extensions` (or `edge://extensions`, `opera://extensions`).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and select the unzipped folder.

## How it works
The extension copies the presentation link and opens https://slidesharedownloadr.com/, where you click the paste button and Download.

## Permissions
`activeTab`, `contextMenus`, `clipboardWrite` only. No tracking, no data collection.
